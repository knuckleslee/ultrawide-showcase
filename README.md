# UltraWide Studio — 5120 × 1440 Virtual Desktop Showcase

以 **32:9（5120 × 1440）超寬螢幕**為目標的互動展示網頁。這是一個模擬桌面，無需登入 LINE、安裝剪輯軟體或編輯器。

![日常使用場景](demo-initial.png)

## 功能

- **自動展示**：依序播放日常使用、影片剪輯、程式設計場景，搭配放大游標導覽。
- **自由操作**：可拖曳視窗標題列、縮放右下角、最小化／最大化、切換焦點。
- **視窗內容自適應**：依視窗大小調整模擬應用程式版面；應用程式不是實際可操作的生產力工具。
- **自動整理／重設**：切換工作區配置，快速恢復展示。
- **全螢幕展示**：透過網頁按鈕進入全螢幕。
- **新聞內容**：啟用本機 Python 服務時讀取繁體中文台灣 Google News RSS，離線則使用明確標示的示範資料。

![影片剪輯場景](demo-editing.png)

## 使用方法

### 最簡單：純靜態網頁

直接開啟 `index.html` 即可操作三種場景、視窗動畫和展示功能。此方式**不提供即時新聞**。

### 即時新聞：Python 本機服務

需安裝 Python 3，無需第三方套件：

```bash
python server.py
```

接著在瀏覽器開啟 <http://127.0.0.1:8765/>。Windows 也可以雙擊 `啟動展示.bat`。

新聞資料由本機 `/api/news` 提供，使用 Google News RSS，每 5 分鐘更新快取一次。來源無法存取時，網頁會保留示範內容而不宣稱其為最新新聞。

## 操作快捷鍵

| 按鍵 | 功能 |
| --- | --- |
| `1` / `2` / `3` | 切換日常／剪輯／程式場景 |
| `Space` | 暫停／繼續自動展示 |
| `R` | 重設當前場景 |
| `F` | 切換全螢幕 |
| `H` | 顯示／隱藏提示 |
| `Esc` | 離開全螢幕 |

## 部署說明

GitHub Pages 等靜態網站服務可以直接部署 `index.html`，但**無法執行 `server.py`**，因此預設不會有即時新聞。若需要公開網站也更新 RSS，必須另行部署後端或使用排程產生可供靜態網頁讀取的新聞資料。

## 專案結構

```
index.html           # 虛擬桌面 UI、三種場景、動畫與互動
server.py            # 可選的本機 RSS API 服務
啟動展示.bat          # Windows 啟動器
demo-initial.png     # 日常模式預覽
demo-editing.png     # 剪輯模式預覽
README.md            # 使用說明
```
